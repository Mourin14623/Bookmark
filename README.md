# Bookmark — E-library

A responsive, browser-based digital library for discovering and saving books.

## Features
- Browse a curated starter collection of classic and public-domain books
- Search by title, author, or genre
- Filter by category
- Save favourites to a personal shelf (stored in browser localStorage)
- View book details and open free online editions where available
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

Book edition links point to Project Gutenberg. Cover artwork is loaded from Open Library Covers.
