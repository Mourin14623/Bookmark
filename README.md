# Bookmark — E-library

Bookmark is a responsive, browser-based digital library with a built-in PDF reading experience.

## Features
- Discover featured books and browse the full collection
- Search books by title or author
- Filter and sort the collection
- Save favourites to **My Shelf**
- Track books as **Reading Now** or **Completed**
- Open PDFs in Bookmark's in-site reader
- Navigate pages, zoom, and use keyboard arrow keys
- Animated page transitions
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a modern browser. The site does not require a build step.
